This replaces the original 0.1.0 package with the corrected AC7 integration. If you downloaded the earlier release, download this archive again and replace all included files.

The engine integration now keeps menus, HUD and mission briefings at full resolution. Background/cloud jitter, low-resolution cloud blocks and the artifacts on small aircraft details are corrected. Lighting, reflections and post-processing are preserved. FSR and XeSS use an optimized D3D11/D3D12 transfer path, and FSR 4 INT8 compatibility is included for supported NVIDIA/Intel devices.

### Included

- DLSS Super Resolution / DLAA, FSR 2.3.4, FSR 3.1.5, FSR 4.1.1 and XeSS SR 2.0.2.
- The AC7 game plugin, DirectInput loader and Insert overlay, with a fading startup hotkey hint.
- Required vendor runtimes, licenses, installation guide and per-file manifest.
- Corresponding source archive and SHA-256 checksums.

### Install and use

1. Close AC7 and download **ReScaleFrame-0.1.0-AC7-Windows-x64.zip**.
2. In Steam, choose **Manage > Browse local files** and find `Ace7Game.exe`.
3. Extract the archive there. `dinput8.dll`, `ReScaleFrame.Game.AC7.dll`, `rescaleframe_overlay.dll` and `ReScaleFrame.ini` go beside the executable, with the included `ReScaleFrame` folder. Replace every included file when updating. Back up another mod's `dinput8.dll` before replacing it; proxy chaining is not supported.
4. Launch normally. Press **Insert** to enable/disable upscaling, select the backend and choose Native, Quality, Balanced, Performance or Ultra Performance.

The first launch uses DLSS Performance. Native uses DLAA with DLSS. Enable and quality settings are saved; choose alternate backends again after restarting. Turning upscaling off restores native scene rendering.

### Requirements and validation

Steam AC7 on Windows 10/11 x64, tested executable build 9855922, with a current GPU driver and the [Visual C++ x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe). DLSS requires NVIDIA RTX. FSR 4 compatibility on NVIDIA/Intel requires Shader Model 6.6 and wave operations; unsupported selections retain the current working backend. First-use FSR 4 shader compilation can pause the game.

The corrected build was accepted in game on RTX 4070 Laptop. Release build/tests, actual overlay rendering and explicit backend/switching GPU fixtures passed. Other GPU families have not received the same AC7 visual validation, and FPS gains vary by backend and scene.

Frame generation, Reflex, the standalone launcher and WSGM integration are not included.

To uninstall, close the game and remove the files copied from the archive. Settings are in `%LOCALAPPDATA%\ReScaleFrame\AC7.ini`; logs are in `%LOCALAPPDATA%\ReScaleFrame\AC7\`. [Report an issue](https://github.com/KillerPixelCrew/ReScaleFrame/issues) with your GPU, driver, backend, preset, resolution and relevant log excerpt.
