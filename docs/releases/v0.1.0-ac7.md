The first AC7 release is ready. DLSS starts with the game, the UI stays sharp, and the briefing
terrain and aircraft icons now render at full resolution without inheriting the scene's jitter.

### Install

1. Download **ReScaleFrame-0.1.0-AC7-Windows-x64.zip** below.
2. Close AC7. In Steam, choose **Manage > Browse local files** and find `Ace7Game.exe`.
3. Extract the ZIP into that folder. `dinput8.dll`, `rescaleframe_overlay.dll` and
   `ReScaleFrame.ini` should sit beside the executable, with the included `ReScaleFrame` folder.
4. Launch normally. No developer hotkeys or Windows launch options are needed.

The DLSS runtime is included. You need an NVIDIA RTX GPU with DLSS support and the
[current Visual C++ x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe).

If another mod already uses `dinput8.dll`, don't overwrite it. This build does not chain other
DirectInput proxies.

### Use

Press **Insert** to open the overlay. Turn **Enable DLSS** on or off and choose a preset:

- **Native** uses DLAA at your output resolution.
- **Quality**, **Balanced**, **Performance** and **Ultra Performance** control the scene's render scale.

Performance is the default. Your choices are saved for the next launch. The briefing layer stays
at full resolution whichever preset you choose. Turning DLSS off restores native rendering.

### Scope

This release is for the Steam version of AC7 on Windows x64, tested with build 9855922.
It includes DLSS Super Resolution and DLAA. Frame generation, Reflex, XeSS and FSR will come
separately; other game builds and Proton have not been validated with this release.

To uninstall, close the game and remove the files you copied in. Saved preferences are in
`%LOCALAPPDATA%\ReScaleFrame\AC7.ini`; logs are in `%LOCALAPPDATA%\ReScaleFrame\AC7\`.

If you run into a problem, [open an issue](https://github.com/KillerPixelCrew/ReScaleFrame/issues)
with your GPU, driver, preset, resolution and the relevant log excerpt.

Thanks for trying it. The source archive, checksums and third-party notices are included.
