# Drag'n Wash 0.1.1 build record, 18 October 2026

This package updates the Unity integration to the current shared runtime and overlay,
including the post-processing correction, independent SR/FG provider selection, DLSS
model selection and guarded RTX 40 MFG support. The managed adapter's rendering and
private-contract code is unchanged. The target remains Steam build 25286774,
Unity 6000.3.14f1 Mono/URP RenderGraph, D3D12.

## Build inputs and correction

The old scripts required a game Managed directory and a deployed manifest. Those were
unnecessary build dependencies. Builds now accept a prepared SDK reference cache, and
packaging assembles an explicit allowlist from Release outputs and vendor SDKs. Neither
operation requires an installed game. Unity DLLs remain compile-only and are excluded
from the package. No CI workflow was changed.

Engine references came from the official Unity 6000.3.14f1 Editor SDK, revision
`d68c3f99a318`. Its Windows installer SHA256 is
`33617234700b669f1ce73a3c8b48fcf64694f57dbc24c26cc323ed6e44f37cc9`.
The SDK's template cache lacked URP binaries. An attempt to compile a public URP 17.3.0
project exited 198 because this machine has no active Editor license. No game files
or license workaround were used.

Compilation instead used the official Unity 6000.4.7f1 SDK template's URP 17.4.0
assemblies alongside the pinned 6000.3.14f1 engine modules. These are compile references,

## Checks and limits

The managed helper and native runtime/plugin/carrier built in Windows Release with
locked Harmony 2.4.2 and the public SDK references. The native verification gate passed
44 checks with eight opt-in skips; Rust formatting and Clippy passed.

The managed metadata fixture against URP 17.4.0 failed its preflight because
`PostProcessPassRenderGraph` is absent there. This confirms that those newer assemblies
are not a substitute for target-player contract acceptance. The helper retains the
existing twelve-method preflight before installing any Harmony patch. A new target-player
contract run and a fresh game session were not performed on this machine.

Recorded target-player SR/FG image and switching acceptance remains the earlier
[Unity runtime](../research/unity-dx12-runtime-20261004.md) and
[shared FG](../research/shared-fg-20261004.md) evidence. Higher MFG counts, scene/resize
coverage and MSI Claw acceptance remain bounded by those records. Packaging checks
do not establish live game image quality, latency or performance.
